পার্টি ও মালামালের হিসাব - Android Studio Project

এই ফোল্ডারটি Android Studio-তে খুলে APK বানানো যাবে।

ধাপ:
1. Android Studio ইনস্টল করুন।
2. File > Open থেকে PartyMalHisab ফোল্ডারটি নির্বাচন করুন।
3. Gradle sync শেষ হওয়া পর্যন্ত অপেক্ষা করুন।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
5. APK তৈরি হলে Android Studio-তে 'locate' চাপলে ফাইলটি পাবেন।

অ্যাপের ডেটা ফোনের অ্যাপ-স্টোরেজে থাকে। অ্যাপের ডেটা মুছে ফেললে হিসাব মুছে যেতে পারে।
এখনকার প্রকল্পে ইন্টারনেট পারমিশন নেই; হিসাব অফলাইনেই কাজ করবে।
